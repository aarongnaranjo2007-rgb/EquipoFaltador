## Flujo de Trabajo
1. Toda tarea se define previamente como un **Issue** en el tablero con su estimación y prioridad.
2. Cada funcionalidad o documento se desarrolla en una rama específica (`docs/...`, `feature/...`).
3. La integración en `main` se realiza exclusivamente mediante **Pull Request** cerrando el issue con `Closes #N`.
4. Es obligatoria la revisión y aprobación formal de un compañero. Queda prohibido el auto-merge.
